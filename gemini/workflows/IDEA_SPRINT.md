# Workflow: Idea Sprint (10–20 min)

Use when you need options fast — panel copy, quest updates, intro hooks, inventory lore, or mobile polish angles.

## Setup

Gem: **Nexus Prime Director**  
Mode: `/ideas`

## Sprint card (copy)

```
IDEA SPRINT
Constraint: stay inside PRODUCT_BIBLE + STYLE_GUIDE + active systems/
Axis to explore: [Character bio / quest status / inventory item / mobile panel / intro CTA / ecosystem cross-link]
Quantity: 8
Timebox: one reply, then I feedback
Desktop rule: flag any idea that changes lg+ layout as HIGH RISK
```

## Feedback protocol (immediate iteration)

Reply with only one of:

- `KEEP #3` — develop into `/brief`  
- `TWIST #3` + note (`more RPG humor` / `shorter bio` / `stronger quest hook`)  
- `SCRAP` — new 8, avoid X  
- `HYBRID 2+5` — merge  

Gemini must regenerate in ≤1 reply using that instruction.

## Play modes (rotate)

1. **Character sheet** — stats and bio only, no new panels  
2. **Quest board** — ecosystem status honesty  
3. **Inventory lore** — one item deep dive  
4. **Mobile app** — max-lg improvements only  
5. **Intro boot** — enter + loading copy  
6. **Opposite day** — invert obvious portfolio pattern; keep purple RPG canon  

## Promotion rule

Nothing from a sprint is canon until you say:

`LOCK: put this into gemini/systems/[FILE].md under [section]`

Then ask Gemini for `/lock` paste-ready markdown.
